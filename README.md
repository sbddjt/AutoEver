# 🚀 Python Advanced & OOP Study

이 저장소는 파이썬의 객체지향 프로그래밍(OOP) 핵심 원칙과 고급 기능을 체계적으로 정리한 학습 저장소입니다.

## 📁 Repository Structure

### 1. [01_OOP_Fundamentals](./01_OOP_Fundamentals)
- **핵심:** 클래스 정의, 생성자(`__init__`), 소멸자(`__del__`), 메모리 최적화(`__slots__`)
- **주요 내용:** 정보 은닉(Access Modifiers), Getter/Setter, Static/Class Method

### 2. [02_OOP_Advanced](./02_OOP_Advanced)
- **핵심:** 코드 재사용성과 유연한 설계를 위한 고급 기법
- **주요 내용:** 상속(Inheritance), 다중 상속 및 MRO, 다형성(Polymorphism), 추상 클래스(ABC)

### 3. [03_Modules_and_Packages](./03_Modules_and_Packages)
- **핵심:** 파이썬의 모듈 시스템과 외부 패키지 관리
- **주요 내용:** `import` 메커니즘, `sys.path` 관리, 환경변수 활용

### 4. [04_Practice_Problems](./04_Practice_Problems)
- **실습:** 수업 중 진행한 알고리즘 및 미니 프로젝트
- **예제:** 숫자 삼각형 출력, 주소록 관리 프로그램(AddressBook)
