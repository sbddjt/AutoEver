## 📚 Curriculum & Learning Logs

각 주차별 핵심 학습 내용을 정리한 링크입니다. (상세 내용은 해당 폴더 내 MD 파일 참조)

### [Phase 1: Cloud & Infrastructure]
- **Week 1-2:** Linux OS 심화 및 네트워크 기초
- **Week 3-4:** 가상화 기술 및 Docker 컨테이너 기초
- **Week 5-6:** AWS Core Service (EC2, VPC, S3, RDS) 설계 및 구축

### [Phase 2: Cloud Native & DevOps]
- **Week 7-8:** Kubernetes 클러스터 운영 및 오케스트레이션
- **Week 9-10:** IaC(Terraform)를 활용한 인프라 자동화
- **Week 11-12:** CI/CD 파이프라인 구축 (Jenkins/GitHub Actions)

### [Phase 3: Mobility Project]
- **최종 프로젝트:** 모빌리티 도메인 기반 클라우드 아키텍처 설계
