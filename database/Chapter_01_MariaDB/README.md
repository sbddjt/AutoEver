# 🗄️ [DB] MariaDB 기초 및 환경 설정

## 1. MariaDB 개요 🧊

1. **정의:** SQL에 기반을 둔 오픈 소스 관계형 데이터베이스 관리 시스템(RDBMS)입니다.
2. **작업 단위:** `데이터베이스(Database) > 테이블(Table)` 순의 계층 구조를 가집니다.
3. **호칭 방식:** 원래는 `데이터베이스명.테이블명` 형태로 호출해야 하나, 현재 데이터베이스를 선택(use)한 상태라면 데이터베이스 이름은 생략할 수 있습니다.

---

## 2. 설치 및 보안 설정 (DB Server) 🔐

1. **다운로드:** [mariadb.org](https://mariadb.org/download) 공식 홈페이지에서 서버 파일을 내려받습니다.
2. **보안 주의사항:** root 계정의 원격 접근을 허용하면 해킹 위험이 매우 크므로, 특별한 경우가 아니면 외부 접속을 제한하는 것이 안전합니다.
3. **포트(Port) 설정:** 기본 포트 번호를 사용하면 누구나 알 수 있으므로, 충돌이 나지 않는 범위 내에서 번호를 변경하여 보안을 강화할 수 있습니다.
4. **성능 최적화:** 개인 컴퓨터는 버퍼 사이즈가 크면 느려질 수 있으나, 기업용 서버는 별도의 장비를 사용하므로 성능 향상을 위해 버퍼 크기를 크게 설정합니다.

---

## 3. 접속 도구 설정 (DBeaver) 🛠️

1. **다운로드:** [dbeaver.io](https://dbeaver.io/download)에서 커뮤니티 버전을 설치합니다.
2. **연결 방법:** `새 데이터베이스 연결 > MariaDB`를 선택합니다.
3. **접속 정보:** * **Server Host:** `localhost` (본인 PC 설치 시).
    - **Database:** 초기 연결 시 `mysql`을 입력합니다.
    - **Authentication:** root 계정의 비밀번호를 입력하여 연결을 마무리합니다.
4. **네트워크 환경:** 강의실 등 로컬 네트워크 환경에서는 와이파이 접속보다 유선 연결이 권장됩니다. 허브를 통한 로컬 전송 시 모든 컴퓨터에 데이터가 전송되어 트래픽이 증가할 수 있기 때문입니다.

---

## 4. 데이터베이스 관련 주요 명령어 💻

1. **데이터베이스 확인:** `show databases;` (전체 DB 목록 조회).
2. **현재 데이터베이스 확인:** `select database();` (현재 선택된 DB 표시).
3. **데이터베이스 생성:** `create database 이름;` (새로운 작업 공간 생성).
4. **데이터베이스 삭제:** `drop database 이름;` (기존 DB 삭제).
5. **데이터베이스 변경:** `use 이름;` (작업할 DB 선택).
6. **테이블 확인:** `show tables;` (현재 DB 내의 테이블 목록 조회).

---

## 5. SQL 실습 스크립트 📝

```sql
- 1. 전체 데이터베이스 목록 확인
show databases;
- 2. 현재 작업 중인 데이터베이스 확인 (초기엔 null일 수 있음)
select database();
- 3. 본인 이름의 데이터베이스 생성
create database seongyun;
- 4. 생성한 데이터베이스로 전환하여 사용 시작
use seongyun;
- 5. 전환이 잘 되었는지 다시 확인
select database();
- 6. 해당 데이터베이스 내부에 생성된 테이블이 있는지 확인
show tables;
```

---

## 6. 실습 팁 및 주의사항 💡

1. **스크립트 대량 실행:** 실행할 코드가 많을 때는 마우스로 드래그한 후 `SQL 스크립트 실행` 기능을 사용하면 한꺼번에 처리됩니다.
2. **CLI 활용:** DBeaver뿐만 아니라 MariaDB 프롬프트(터미널)에서도 직접 SQL문을 실행할 수 있습니다.
