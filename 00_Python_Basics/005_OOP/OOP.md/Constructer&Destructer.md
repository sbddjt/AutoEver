# 🏗️ Python: 객체의 생명 주기와 메모리 관리

## 1. 특수 속성 (Special Attribute)

> __ (더블 언더바)로 시작하고 끝나는 속성으로, 파이썬 인터프리터가 특별한 목적으로 사용하도록 제공함.
> 
- **`__doc__`**: 함수나 클래스의 도움말(Docstring)을 저장하는 속성. 설정하지 않으면 `None`이며, 실행 중에 수정(쓰기)도 가능함. 협업 시 코드의 목적을 명시할 때 필수적임.

## 2. 생성자 (Constructor): `__init__`

인스턴스를 생성할 때 **메모리 할당(Allocation)**과 **초기화(Initialization)** 작업을 동시에 수행함.

### ✅ 왜 `__init__`을 사용하는가?

기존 방식은 인스턴스 생성 후 여러 개의 `set` 메서드를 일일이 호출해야 했으나, 생성자를 사용하면 **객체 생성과 동시에 값을 채울 수 있어** 코드가 간결해짐.

- **기존 방식**: 3줄 소요

```python
addr = Address()
addr.set_id()
addr.set_name("홍길동")
```

- **생성자 방식**: 1줄로 해결

```python
addr = Address("홍길동", "010-1234-5678")
```

### 💡 매개변수 초기화 (Default Parameter)

## 3. 소멸자 (Destructor): `__del__`

인스턴스가 메모리에서 소멸될 때 자동으로 호출되는 메서드.

- **형식**: `def __del__(self):` (매개변수는 `self` 1개)
- **목적**: 객체가 사용하던 자원을 안전하게 반납(Clean-up)하기 위함.

### ⚠️ 자원 해제 미흡 시 발생하는 문제 (강사님 강조)

| **구분** | **발생 현상** | **결과** |
| --- | --- | --- |
| **파일 시스템** | 파일을 닫지(`close`) 않고 객체 소멸 | **파일 잠금(File Lock)** 상태 지속, 타 프로그램 접근 불가 |
| **네트워크/DB** | 연결(`Connection`) 유지 상태로 소멸 | 서버 세션 고립, **동시 접속 제한**으로 시스템 마비 |
| **메모리** | C언어 라이브러리 연동 시 해제 누락 | **메모리 누수(Leak)** 발생, 시스템 성능 급격히 저하 |

## 4. 파이썬의 메모리 관리: 참조 카운트 (Reference Count)

파이썬은 수동 메모리 해제 대신 **참조 카운트(RC)** 방식을 사용하여 가비지 컬렉션을 수행함.

### 🔄 참조 카운트 작동 원리

1. **데이터 할당 시**: RC = 1
2. **다른 변수가 참조 시**: RC += 1 (예: `address4 = address`)
3. **참조 해제 시**: RC -= 1 (예: `address = None` 또는 `del address`)
4. **RC == 0 이 되는 순간**: 메모리 해제 및 **`__del__` 호출**

### 💡 `address = None`의 의미 (명시적 해제)

강사님이 사용하신 `address = None`은 변수와 객체 사이의 연결 고리를 끊는 행위입니다.

- **변수는 유지하되 가리키는 대상만 제거**하여 RC를 즉시 감소시킴.
- 중요한 자원을 점유 중인 객체를 **가비지 컬렉터가 즉시 수거하도록 유도**하는 가장 깔끔한 방법.

---

## 💻 종합 실습 코드 (Address 클래스)

```python
class Address:
    auto_increment = 1
    
    def __init__(self, name, phone = "전화번호없음"):
        self.id = Address.auto_increment
        self.name = name
        self.phone = phone
        Address.auto_increment += 1
        print(f"✨ ID {self.id} 생성 완료")

    def __del__(self):
        print(f"🗑️ ID {self.id} 메모리 해제 및 자원 반납 (소멸자 호출)")

# --- 테스트 시작 ---
print("1. address 생성")
address = Address("홍길동", "010-1234-5678") # RC = 1

print("\n2. address2에 복사")
address2 = address # RC = 2 (같은 객체를 두 명이 가리킴)

print("\n3. address 변수 삭제")
del address  # RC = 1 (이름표 하나가 떼졌지만, address2가 아직 잡고 있음)
print("-> 아직 소멸자가 안 떴죠?")

print("\n4. address2 변수 삭제")
del address2 # RC = 0 (마지막 이름표가 떼짐! 이때 소멸자 호출)

print("\n--- 프로그램 종료 ---")
```

### 💡 소멸자를 유도하는 두 가지 방법

1. **`address = None` (참조 변경)**
    - **의미**: "이 변수는 이제 다른 것(`None`)을 가리킬 거야."
    - **결과**: 기존 객체와의 연결이 끊기면서 RC가 1 감소합니다. 변수(`address`) 자체는 메모리에 남아서 나중에 다른 값을 담을 수 있습니다.
    - **용도**: 특정 객체와의 관계만 깔끔하게 정리하고 싶을 때 주로 사용합니다.
2. **`del address` (이름 삭제)**
    - **의미**: "이 변수(이름표) 자체를 아예 없애버릴 거야."
    - **결과**: 변수 이름이 사라지면서 해당 이름이 가리키던 객체의 RC가 1 감소합니다. 이후에는 `address`라는 이름을 다시 쓰려면 다시 선언해야 합니다.
    - **용도**: 더 이상 해당 변수 이름을 사용할 일이 없을 때 확실하게 지우기 위해 사용합니다.
