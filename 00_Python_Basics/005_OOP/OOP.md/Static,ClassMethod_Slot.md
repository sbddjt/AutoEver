# 🛠️ Python: 클래스 고급 기능 및 데이터 보호

## 1. 클래스 레벨 메서드 (Static & Class Method)

> 인스턴스를 생성하지 않고 클래스 이름으로 직접 호출하는 메서드들입니다.
> 

| **구분** | **Static Method** | **Class Method** |
| --- | --- | --- |
| **데코레이터** | `@staticmethod` | `@classmethod` |
| **첫 번째 매개변수** | 없음 (self 사용 불가) | `cls` (클래스 자신) |
| **특징** | 일반 함수와 비슷하나 클래스 내부에 위치함 | 상속 시 호출한 클래스를 인지함 |
| **주요 용도** | 클래스 변수의 초기화 및 유틸리티 | 클래스 속성 제어, 팩토리 메서드 |

## 2. 속성 동적 생성과 `__slots__`

파이썬은 실행 중(`Runtime`)에 인스턴스 속성을 마음대로 추가할 수 있는 유연한 언어입니다.

### ⚠️ 동적 생성의 위험성

- **일관성 결여**: 클래스 설계 시 의도하지 않은 속성이 마구잡이로 생길 수 있음.
- **메모리 낭비**: 파이썬은 내부적으로 `__dict__`를 통해 속성을 관리하므로 메모리 사용량이 많음.
- **CS 인사이트**: 이는 **NoSQL(Schema-less)**과 **RDBMS(Schema-fixed)**의 차이와 유사함. (유연함 vs 엄격한 구조)

### 🔒 `__slots__`를 통한 제한

클래스에 `__slots__`를 정의하면 리스트에 명시된 속성 이외에는 생성할 수 없도록 강제합니다.

```python
class Address:
    # 지정된 속성 이외의 동적 생성 차단
    __slots__ = ['id', 'name', 'phone']
```

## 3. 접근 지정자 (Access Modifier)

데이터에 대한 접근 권한을 제한하여 **캡슐화(Encapsulation)**를 실현합니다.

### 🛡️ Public vs Private

- **Public (기본값)**: 어디서든 접근 가능.
- **Private (`__`)**: 속성 이름 앞에 언더바 두 개를 붙이면 클래스 외부에서 인스턴스를 통해 직접 접근할 수 없음.

### 📑 실무 권장 사항 (Getter / Setter)

속성을 직접 변경하기보다는 검증 로직이 포함된 **접근자 메서드**를 통해 데이터를 다루는 것을 권장합니다.

```python
# 1. Private 설정 (__ 사용)
class Address:
    __slots__ = ["__id", "__name", "__phone"] # Private 변수들만 허용

# 2. 테스트 코드
address = Address("홍길동", "010-1234-5678")

# [실패] 인스턴스를 통한 직접 접근 (Error 발생)
# address.__name = "adam" 

# [성공] 접근자 메서드를 통한 안전한 변경
address.set_name("adam")
print(address.get_name())
```
