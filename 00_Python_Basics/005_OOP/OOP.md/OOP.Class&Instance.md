# 🏗️ 클래스 구성과 메모리 원리

## 1. 클래스의 구성 요소

객체 지향 프로그래밍에서 클래스는 크게 두 가지로 구성됩니다.

- **Attribute (속성)**: 객체가 가지는 **데이터** (변수)
- **Method (메서드)**: 객체가 수행하는 **작업** (함수)

---

## 2. 클래스(Class) vs 인스턴스(Instance)

| **구분** | **클래스 (Class)** | **인스턴스 (Instance)** |
| --- | --- | --- |
| **개념** | 설계도, 자료형 (Type) | 설계도를 기반으로 실제 생성된 실체 |
| **가변성** | 기본적으로 **불변** | 메모리를 할당받은 **동적** 데이터 |
| **생성** | 정의 영역 | `클래스이름([데이터])` 형식으로 생성 |

> 💡 호출 규칙
> 
> 
> 클래스나 인스턴스의 내부 구성 요소(속성, 메서드)를 호출할 때는 마침표(.) 연산자를 사용합니다.
> 

---

## 3. 인스턴스 메서드 생성과 `self`

인스턴스가 호출할 수 있는 메서드는 클래스 내부에 정의합니다.

- **정의 형식**: `def 메서드이름(self, [데이터]):`
- **`self`의 의미**: 인스턴스 자신을 가리키는 관례적인 이름입니다.
- **특징**: 인스턴스는 클래스에 생성된 속성과 클래스에 대한 **참조(Reference)** 정보만 가지고 생성됩니다.

---

## 4. 메서드 호출 방식 (Bound vs Unbound)

파이썬에서는 클래스 외부에서 메서드를 호출하는 두 가지 경로가 있습니다.

### A. Bound Method Call (인스턴스 기반)

- **형식**: `인스턴스이름.메서드이름([데이터])`
- **특징**: 인스턴스 주소(ID)가 `self` 인자로 **자동 전달**됩니다. (`addr.printNum()` → `addr`이 자동 투입)

### B. Unbound Method Call (클래스 기반)

- **형식**: `클래스이름.메서드이름(인스턴스, [데이터])`
- **특징**: `self` 자리에 어떤 인스턴스를 넣을지 **수동으로 명시**해야 합니다. 파이썬은 클래스 이름을 통해서도 인스턴스 메서드 호출이 가능합니다.

## 5. 메모리 구조와 관리 (CS 핵심)

### 📂 자료구조와 영역

| **영역** | **특징** | **저장 내용** |
| --- | --- | --- |
| **Stack** | 함수 호출 시 생성되는 임시 영역 | 지역 변수, 매개변수, 함수 리턴 주소 등 |
| **Heap** | 반영구적 영역 (정적/동적 구분) | **정적 영역**: 상수(Literal), **Class** 정보
**동적 영역**: 실제 **Instance** 데이터 |

### ♻️ 언어별 메모리 관리 방식

- **C / C++**: 개발자가 `free()`나 `delete`를 통해 **직접 메모리를 해제**해야 함.
- **Java**: 가비지 컬렉터(GC)가 참조되지 않는 객체를 자동으로 관리.
- **Python**: **Reference Count(참조 횟수)** 방식을 이용.
    - 예: `car = Car()` 실행 시 `Car()` 인스턴스의 참조 횟수가 1이 되어 메모리에서 유지됨.
    - 나를 가리키는 변수가 0이 되면 자동으로 메모리에서 해제됨.

## 💻 코드 실습 예제

```python
class Address:
    # 메서드 정의 (self는 인스턴스 자신)
    def printNum(self):
        print(self.num)

# 1. 인스턴스 생성 및 속성(Attribute) 부여
addr = Address()
addr.num = 10 

# 2. Bound Method Call (권장 방식)
addr.printNum() # 내부적으로 addr의 id가 self로 전달됨

# 3. Unbound Method Call (원리 확인용)
Address.printNum(addr) # 직접 인스턴스를 인자로 전달
```

```python
# 클래스
class Address:
    # 인스턴스가 호출가능한 메서드
    def printAddress(self):
        print("인스턴스 메서드 만들기 연습")

# Address 클래스의 인스턴스 생성
myAddress = Address()

# 바운드 호출: 인스턴스 이름으로 호출
myAddress.printAddress()

# 언바운드 호출: 클래스 이름으로 호출, 인스턴스를 첫 번째 매개변수로 전달
Address.printAddress(myAddress)
```
