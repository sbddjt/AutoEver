# 🐧 VI, VIM 편집기

## 1. 리눅스 편집기의 종류

### 1) 개요

- **기원:** 유닉스(Unix) 시절부터 사용하던 편집기

### 2) 분류

- **행 단위 편집기 (Line Editor)**
    - 한 번에 하나의 행씩 편집하는 도구
    - 종류: `ed`, `ex`, `sed`
- **화면 단위 편집기 (Screen Editor)**
    - **vi (vim):** 리눅스 표준 편집기 (가장 많이 사용)
    - **emacs:** 강력한 기능을 가진 편집기
    - **nano:** 메뉴 기반의 직관적인 편집기 (초보자용)
- **GUI 편집기**
    - **gedit:** 윈도우의 메모장과 유사

### 3) 모드형 vs 비모드형

| **구분** | **모드형 편집기 (Modal)** | **비모드형 편집기 (Modeless)** |
| --- | --- | --- |
| **특징** | **입력 모드**와 **명령 모드**가 별도로 존재 | 입력/명령 모드 구분이 없음 |
| **작동 방식** | 같은 키라도 모드에 따라 **입력**이 되거나 **명령**이 됨 | 편집 기능은 `Ctrl`, `Alt` 등 특수키 조합으로 사용 |
| **대표 예시** | **vi, vim** | **nano**, 메모장 |

## 2. vim (Vi IMproved)

### 1) 개요 및 설치

- `vi` 이후에 개발된 향상된 Editor
- **설치 명령어:**

```bash
sudo apt install vim
```

### 2) 동작 모드 🔄

- **시작:** `vi`를 실행하면 기본적으로 **명령 모드**에서 시작
- **모드 전환:**
    - **명령 ➡ 입력:** `i`, `l`, `a`, `A`, `o`, `O` (커서 위치 차이)
    - **입력 ➡ 명령:** `ESC`
    - **명령 ➡ 마지막 행:** `:`, `/`, `?`
    - **마지막 행 ➡ 명령:** `ESC`, `Enter`
    

### 3) 저장 및 종료 💾

| **명령어** | **설명** |
| --- | --- |
| **`zz`** | 명령 모드에서 저장하고 종료 |
| **`:q`** | 저장하지 않고 종료 (변경 없음) |
| **`:q!`** | **변경 사항이 있어도 강제 종료** |
| **`:wq`** | 저장하고 종료 |
| **`:wq!`** | 강제로 저장하고 종료 |

### 4) 파일 열기 및 작성

**기본 명령어**

```bash
vim [파일 경로]
```

- 파일 존재 시 편집, 없으면 빈 파일 생성
- 경로 생략 시 vim 설명 출력
- 권한 없을 시 `[읽기 전용]`

**실습: 작성하고 저장**

1. `vim test.txt` 입력
2. 입력 모드 진입 (`i`, `a`, `o`)
3. 내용 입력:
    
    ```bash
    ubuntu linux study
    i love linux
    ```
    
4. 저장: `ESC` ➡ `:wq`

## 3. 주요 명령어 및 커서 이동 ⌨️

### 1) 입력 모드 전환 키 (핵심)

| **키** | **설명** |
| --- | --- |
| **`i`** | 커서 **앞**에 입력 (Insert) |
| **`a`** | 커서 **뒤**에 입력 (Append) |
| **`o`** | 커서 **다음 행**에 입력 (Open line) |

### 2) 커서 이동 (명령 모드)

| **명령 키** | **기능** | **방향** |
| --- | --- | --- |
| **k** | 한 행 위로 이동 | ⬆️ |
| **j** | 한 행 아래로 이동 | ⬇️ |
| **l** | 한 글자 오른쪽으로 이동 | ➡️ |
| **h** | 한 글자 왼쪽으로 이동 | ⬅️ |
| **^** 또는 **0** | 현재 행의 **처음**으로 이동 | Home |
| **$** | 현재 행의 **마지막**으로 이동 | End |
| **-** | **앞 행의 처음**으로 이동 |  |
| **+** 또는 **Enter** | **다음 행의 처음**으로 이동 |  |
| **H** | 화면의 **맨 윗행**으로 이동 | High |
| **M** | 화면의 **중간 행**으로 이동 | Middle |
| **L** | 화면의 **맨 아랫행**으로 이동 | Low |
| **w** | **다음 단어** 첫 글자로 이동 | Word |
| **b** | **앞 단어** 첫 글자로 이동 | Back |
| **e** | **다음 단어** 마지막 글자로 이동 | End |

### 3) 화면 이동 (스크롤)

| **단축키** | **기능** |
| --- | --- |
| **Ctrl + u** | 반 화면 위로 (Up) |
| **Ctrl + d** | 반 화면 아래로 (Down) |
| **Ctrl + b** | 한 화면 위로 (Page Up) |
| **Ctrl + f** | 한 화면 아래로 (Page Down) |

### 4) 특정 행 이동

- **`행번호G`**: 예) `10G`
- **`:행번호`**: 예) `:10` (코딩 시 유용)

## 4. 편집 기능 ✂️

### 1) 내용 삭제 (Delete)

| **명령어** | **설명** |
| --- | --- |
| **`x`, `#x`** | 글자 삭제 |
| **`dw`, `#dw`** | 단어 삭제 |
| **`dd`, `#dd`** | **행(줄) 삭제** |
| **`D`** | 커서부터 행 끝까지 삭제 |

### 2) 명령 취소 (Undo) ↩️

- **`u`**: 명령 취소 (Ctrl+z)
- **`U`**: 해당 행의 모든 명령 취소
- **`:e!`**: 마지막 저장 이후 작업 취소 (새로 고침)

### 3) 복사 및 붙여넣기 📋

- **`yy`, `#yy`**: 행 복사 (Yank)
- **`p`**: 커서 **아래**에 붙여넣기
- **`P`**: 커서 **위**에 붙여넣기

## 5. 실습 예제 (Step-by-Step) 🛠️

1. **파일 생성:** `vim exec.txt`

1. **내용 작성:** (`i` 입력)
    
    ```bash
    Good morning everyone
    Nice to meet you
    I am linux beginner
    Now introduce yourself
    ```
    

1. **저장:** `ESC` ➡ `:w`

1. **수정 작업:**
    - **3행 이동:** `:3`
    - **단어 수정:** `/beginner` ➡ `cw` ➡ `expert` 입력 ➡ `ESC`
    - **2행 단어 삭제:** `:2` ➡ `/meet` ➡ `dw`
    - **2행 부분 삭제:** `/you` ➡ `d$` (끝까지 삭제)
    - **복원:** `u`

1. **최종 저장:** `:w`

## 6. 고급 기능 (검색 & 치환) 🔍

### 1) 내용 검색

- **`/문자열`**: 아래 방향 검색 ⬇️
- **`?문자열`**: 위 방향 검색 ⬆️
- **`n`**: 다음 문자열 (원래 방향)
- **`N`**: 다음 문자열 (반대 방향)

### 2) 치환 (Substitute) 🔄

- **`:s/old/new/`**: 현재 행 첫 번째 문자열 치환
- **`:%s/old/new/g`**: **파일 전체** 문자열 치환
- **`:<범위>s/old/new/gc`**: 치환 여부 확인하며 진행 (Check)
- **`:set ignorecase`**: 대소문자 무시

> 팁: 대소문자 변환
> 
> - Visual Mode (`v`)로 선택 후 `u` (소문자), `U` (대문자)

### 3) 파일 및 쉘 명령

- **`:r 파일`**: 파일 내용을 커서 위치에 삽입
- **`:e 파일`**: 다른 파일 열기
- **`:!명령`**: vi 실행 중 쉘 명령어 수행 (예: `:!ls`)
- **`Shift + j`**: 현재 행과 아랫행 연결

## 7. 환경 설정 (`.vimrc`) ⚙️

### 1) 설정 방법

- 홈 디렉토리의 `.exrc` 또는 `.vimrc` 파일 수정
- `vi` 마지막 행 모드에서 `:set` 명령으로 일시 적용 가능

### 2) 주요 옵션

| **옵션** | **설명** |
| --- | --- |
| **`set nu`** | 줄 번호 표시 |
| **`set nonu`** | 줄 번호 숨김 |
| **`set list`** | 공백/탭 문자 표시 |
| **`set showmode`** | 현재 모드 표시 |
| **`set all`** | 모든 설정값 출력 |
