# 🐧 리눅스 쉘(Linux Shell)

## 1. 📝 개요

**정의 및 역할**

- 사용자가 입력한 명령을 해석하여 커널(Kernel)로 전달하고, 커널의 처리 결과를 사용자에게 전달하는 **매개체** 역할 수행
- Server의 텍스트 모드(CLI)나 X 윈도(GUI)의 터미널처럼 명령을 입력하는 인터페이스

**주요 기능**

- **🗣️ 명령어 해석기:** 사용자의 명령을 컴퓨터 언어로 변환
- **💻 프로그래밍 (Shell Programming):** 자체 내에 프로그래밍 기능 탑재
    - **Shell Script:** 여러 명령을 사용하여 반복적으로 수행하는 작업을 하나의 프로그램으로 만든 것
- **⚙️ 사용자 환경 설정:**
    - 초기화 파일을 통해 사용자별 맞춤 환경 설정 가능
    - 명령어 경로(PATH), 파일/디렉토리 생성 시 기본 권한, 환경 변수 등 설정
    - 로그인 시 초기화 파일이 실행되어 설정이 적용됨
    

---

## 2. 🗂️ 쉘의 종류

| **쉘 이름** | **특징** |
| --- | --- |
| **sh** (Bourne Shell) | 최초의 쉘. 현재는 대부분 bash로 대체됨. |
| **csh** (C Shell) | 2BSD 유닉스 발표. C 언어와 유사한 문법. |
| **ksh** (Korn Shell) | AT&T 개발. SVR4 유닉스 발표. |
| **bash** (Bourne Again Shell) | **리눅스 표준(기본) 쉘**. sh와 호환되며 csh, ksh의 편리한 기능 포함. |
| **tcsh** | csh의 기능을 확장하여 개발된 C쉘 계열. |
| **dash** | sh 기반. 크기가 작고 가벼움. |
| **zsh** (Z Shell) | bash와 tcsh의 기능 + 독자적 편의 기능 (최근 인기). |

## 3. 🔄 Login Shell & Sub Shell

- **Login Shell:** 리눅스에 처음 접속(로그인)했을 때 실행되는 기본 쉘
- **Sub Shell:** 사용자가 프롬프트 상에서 다른 쉘을 실행했을 때 생성되는 쉘 (부모-자식 관계)

> 🚪 **종료 방법 및 차이점**
> 
> - 종료 명령: `Ctrl + d` 또는 `exit`
> - **Sub Shell 종료 시:** 이전 쉘(부모 쉘) 환경으로 돌아감
> - **Login Shell 종료 시:** 터미널이 종료되거나 원격 접속이 해제

## 4. 🐚 Bash Shell 특징

**Ubuntu 등 리눅스 배포판에서 기본 제공**

- **Alias:** 별칭 기능 제공 (긴 명령어를 짧게 줄여 사용)
- **History:** 사용한 명령어 기록 및 재사용 기능
- **연산 기능:** 쉘 내부에서 산술 연산 가능
- **Job Control:** 백그라운드/포그라운드 작업 제어
- **자동 완성:** `Tab` 키를 이용한 명령어/파일명 자동 완성
- **프롬프트 제어 & 명령 편집:** 사용자 편의성 제공

## 6. ⚙️ Shell 변경

### 1) 현재 사용자의 로그인 쉘 확인

`/etc/passwd` 파일에서 확인 가능합니다.

```bash
# 형식: grep [계정이름] /etc/passwd
grep seongyun /etc/passwd
```

### 2) C Shell 설치 (예시)

```bash
sudo apt install csh
cat /etc/shells  # 설치 확인
```

### 3) 쉘 변경 명령어 (`chsh`)

영구적으로 로그인 쉘을 변경할 때 사용합니다.

- **형식:** `chsh [옵션] [사용자 계정]`
- **옵션:**
    - `s [경로]`: 지정하는 쉘로 로그인 쉘 변경 (**반드시 절대 경로** 사용)
    - `l`: `/etc/shells`에 지정된 사용 가능한 쉘 목록 출력
    

> 💡 **절대 경로 vs 상대 경로**
> 
> - **절대 경로:** 루트(`/`)부터 시작하는 경로 (불변)
>     - 예) `/bin/bash`, `/usr/bin/python`
> - **상대 경로:** 현재 위치(`.`)로부터의 경로
>     - `./`: 현재 디렉토리 (생략 가능)
>     - `../`: 상위 디렉토리

### 4) 변경 예시

```bash
# adam 계정의 쉘을 csh로 변경
chsh -s /bin/csh seongyun

# 다시 bash로 복구
chsh -s /bin/bash seongyun
```

- ⚠️ **주의:** `chsh`로 변경한 내용은 **재접속(로그아웃 후 로그인)** 해야 반영됩니다.

> **💡 [참고] 일회성 쉘 변경 (Sub Shell)**
> 
> 
> ```bash
> # 쉘 이름 -s sh 사용자 계정 형태
> csh -s sh seongyun
> ```
> 
> - 이것은 기본 설정을 바꾸는 `chsh`와 다릅니다.
> - 현재 쉘 위에 새로운 쉘을 덧씌우는 방식입니다.
> - `exit`를 입력하면 껍데기가 벗겨지듯 원래 쉘로 돌아옵니다.
> - 재접속 시 설정이 유지되지 않습니다. (일회성)

## 7. 🛠️ 쉘 내장 명령 (Built-in)

- **개요:** 쉘 프로그램 자체에 내장된 명령어. 별도의 실행 파일(`/bin` 등)이 없음.
- **확인 방법 (`file` 명령):**
    - `file /usr/bin/pwd`: 실행 파일이 존재함 (외부 명령)
    - `file cd`: 파일 확인 불가능 (**내장 명령**)

### 출력 명령

**1) echo**

- 화면에 문자열이나 변수 값 출력

```bash
echo -n "문자열"  # -n: 줄바꿈 안 함
```

**2) printf (C언어 스타일의 서식 지정 출력)**

```bash
printf linux              # 줄바꿈 안됨
printf "linux\n"          # 줄바꿈 포함
printf "%d + %d = %d\n" 1 3 4  # 서식 지정 출력
```

## 8. 🔣 특수문자 (Wildcard & Regex)

쉘은 사용자의 명령을 실행하기 전, 

특수문자를 먼저 해석(해독)하여 **적절한 형태로 변경한 후 실행**합니다.

### 와일드카드 (Wildcard)

| **기호** | **설명** | **예시 명령어** |
| --- | --- | --- |
| **`*`** | **모든 문자열** (길이 상관없음) | `ls *` (모든 내용 출력)
`cp * /tmp` (전체 복사)
`ls -F t*` (t로 시작하는 모든 것) |
| **`?`** | **문자 한 개** 매칭 | `ls t??` (t로 시작하는 3글자 파일) |
| **`[ ]`** | **대괄호 안의 문자 중 하나** | `ls tmp[135].txt` (tmp1, tmp3, tmp5 찾기) |
| **`-`** | **범위** 지정 | `[a-z]` (소문자)
`[A-Za-z][0-9]` (영문+숫자 조합)
`[가-힣]` (한글) |
| **`[^]`** | **제외** (NOT) | `[^abc]` (a, b, c를 제외한 문자) |
| **`^`** | **줄의 시작** | `^root` (root로 시작하는 줄) |
| **`$`** | **줄의 끝** | `bash$` (bash로 끝나는 줄) |

### 주요 특수문자 기억하기

- **`~`**: 사용자 홈 디렉토리 (`cd ~`)
- : 직전 디렉토리 (`cd -`)
- **``` (백틱)**: 명령어 실행 결과를 문자열로 대체
    
    ```bash
    echo "Today is `date`"  # date 명령 실행 결과 출력
    ```
    
- **`;` (세미콜론)**: 여러 명령 순차 실행 (앞 명령 실패해도 계속 진행)
- **`&&`**: 앞 명령이 **성공해야만** 다음 명령 수행
- **`|` (파이프)**: 앞 명령의 결과를 뒤 명령의 입력으로 전달 (`ls -al | more`)
- **`\`**: 특수문자 기능 무력화 (문자 그대로 취급)
- **`' '` (작은따옴표)**: 모든 특수문자 무력화
- **`" "` (큰따옴표)**: `$`, `\`, ``` 등 일부 기능은 허용

## 9. 표준 입출력 장치

### 파일 디스크립터

| **번호** | **이름** | **정의** | **기본 장치** |
| --- | --- | --- | --- |
| 0 | **stdin** | 표준 입력 | 키보드 |
| 1 | **stdout** | 표준 출력 | 모니터 |
| 2 | **stderr** | 표준 에러 | 모니터 |

### 1) 출력 리다이렉션 (`>`)

출력의 방향을 변경 (화면 → 파일).

- **`>` (덮어쓰기)**: 기존 내용 삭제 후 저장.
    
    ```bash
    date > date1.txt
    ls -F / > date1.txt  # date 내용 사라짐
    ```
    
- **`>>` (이어쓰기)**: 기존 내용 뒤에 추가.
    
    ```bash
    date >> date1.txt
    ```
    

### 2) 에러 리다이렉션 (`2>`)

에러 메시지를 따로 처리.

```bash
ls abc 2> ls.err       # 에러를 파일에 저장
ls abc 2> /dev/null    # 에러 버리기 (휴지통)
ls abc > ls.out 2>&1   # 표준 출력과 에러를 한 파일에 저장
```

### 3) 입력 리다이렉션 (`<`)

파일의 내용을 명령의 입력으로 사용.

```bash
명령 < 파일경로
```

## 10. 변수

### 종류

- **SHELL 변수**: 현재 쉘에서만 유효 (지역 변수).
- **환경 변수 (Environment Variable)**: 시스템 전체/자식 프로세스까지 유효 (전역 변수).

### 변수 관리 명령어

| **기능** | **명령어/문법** | **예시** |
| --- | --- | --- |
| **확인** | `echo $변수명` | `echo $PATH` |
| **전체 출력** | `env` (환경변수), `set` (모두) | `env` |
| **SHELL 변수 생성** | `변수명=값` (공백 금지) | `HYUNDAI=AUTOEVER` |
| **환경 변수 생성** | `export 변수명=값` | `export HYUNDAI=AUTOEVER` |
| **변수 삭제** | `unset 변수명` | `unset HYUNDAI` |
| **영구 저장** | `.bashrc` 파일에 기록 | `echo 'export ...' >> ~/.bashrc` |

### 주요 환경 변수

**1) 프롬프트 설정 (`PS1`)**

```bash
PROMPT=$PS1           # 현재 프롬프트 백업
PS1='[\u \T] \!$ '    # 사용자, 시간, 히스토리 번호 등으로 커스텀
PS1=$PROMPT           # 복구
```

**2) PATH (매우 중요 ⭐)**

- 명령어 실행 파일을 찾는 경로의 모음.
- **구분자**: 리눅스는 **콜론(`:`)** 사용 **(윈도우의 `;`와 다름 주의).**

**경로 추가 방법**

```bash
# 1. 뒤에 추가 (권장)
PATH="$PATH:~/bin"

# 2. 앞에 추가
PATH="~/bin:$PATH"
```

> 🛠️ **안전한 PATH 변경 습관 (백업 및 복구)**
> 
> 
> 환경 변수를 편집할 때는 실수를 대비해 기존 값을 다른 변수에 백업해두는 것이 좋습니다.
> 

```bash
# 1. 기존 PATH 백업
OLDPATH=$PATH

# 2. PATH 변경 시도 (실수 예시: 콜론 대신 세미콜론 사용)
PATH="$PATH;~/bin"
echo $PATH   # 확인: 잘못된 경로가 들어감

# 3. 원상 복구
PATH=$OLDPATH
echo $PATH   # 확인: 원래대로 돌아옴

# 4. 올바르게 다시 수행
PATH="$PATH:~/bin"
echo $PATH   # 성공
```

**Tip**: 프로그램을 압축 해제(`tar/unzip`)하여 설치한 경우, 실행 파일이 있는 디렉토리 전체 경로를 `PATH`에 추가하면 어디서든 명령어로 실행할 수 있습니다.

**3) LANG (로케일 정보)**

- 현재 로케일 확인: `echo $LANG`
- 지원 로케일 확인: `locale -a`
- 한국어 설정:

```bash
sudo apt update
sudo apt install language-pack-ko
sudo locale-gen ko_KR.UTF-8
```

**4) 기타 환경 변수**

- `HISTFILE`: 실행한 명령어를 저장할 파일 경로
- `HISTFILESIZE`: 실행한 명령어 저장할 개수 (파일)
- `HISTSIZE`: 메모리에 저장할 개수
- `HOME`: 홈 디렉토리
- `SHELL`: 로그인 쉘의 경로
- `PWD`: 현재 작업 디렉토리

## 11. 환경 설정 파일

### 개요

시스템을 사용하는 사용자의 환경을 설정하는 파일로 로그인 할 때마다 무조건 실행되는 파일

**1) 시스템 환경 설정 파일 (유저 무관)**

- `/etc/profile`: 모든 shell에 공통으로 적용. 수행 후 `/etc/profile.d/*.sh` 실행
- `/etc/bash.bashrc`: 시스템 공통 bashrc. 기본 프롬프트 및 sudo 힌트 제공
- `/etc/profile.d/*.sh`: 언어나 명령 별로 각각 필요한 환경 제공

2) 사용자 환경 설정 파일 (홈 디렉토리)

로그인 시 시스템 설정 파일 실행 → 이후 사용자 설정 파일 실행 (덮어쓰기)

- `~/.profile`: 경로 추가 등 사용자 정의 환경 설정. 수행 후 `.bashrc` 실행
- `~/.bashrc`: 히스토리 크기, 기본 별명(Alias), 함수 등 설정
- `~/.bash_logout`: 로그아웃할 때 수행할 내용 설정

### 적용 및 관리

환경 설정 파일을 수정하면 로그아웃 후 다시 로그인해야 적용됩니다. 하지만 `source`를 쓰면 즉시 적용 가능합니다.

```bash
source .bash_aliases # 수정한 환경설정 파일을 바로 적용
```

**별명(Alias) 관리 팁**

```bash
alias c=clear        # 현재 shell에서만 적용 (일회성)

vim .bash_aliases    # 별명을 저장할 수 있는 파일 생성/수정
alias c=clear        # 내용 작성 후 저장
source .bash_aliases # 적용
```

## 12. bash 옵션

### `set` 명령

- `o`: 옵션 기능 활성화
- `+o`: 옵션 기능 비활성화

**1) ignoreeof**

쉘을 빠져나가는 기능 (CTRL + D) 무시

```bash
set -o ignoreeof 
# 이제 CTRL + D를 눌러도 로그아웃되지 않음
```

2) noclobber

덮어쓰기 방지 기능

```bash
touch sample       # 빈 파일 생성
echo $PWD > sample # 출력 방향을 변경해서 내용을 기록
cat sample

set -o noclobber   # 덮어쓰기 방지 기능 활성
echo $PWD > sample # 에러 발생: 파일 수정이 안됨
```
