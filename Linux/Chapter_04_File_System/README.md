# 🐧 파일 시스템 (Linux File System)

## 1. 디렉토리와 파일 개요

### 💡 기본 개념

- **유닉스 철학:** 리눅스는 유닉스의 많은 부분을 계승했습니다.
- **"모든 것은 파일이다":** 시스템 정보, 하드웨어 장치 등 모든 것을 파일로 관리합니다.
- **단일 트리 구조:** Windows는 물리적 디스크(C:, D:)마다 트리가 생기지만, Linux는 시스템 전체에 **단 하나의 트리(Root, `/`)** 구조만 가집니다.

### 📄 파일의 종류

| **종류** | **설명** | **특징** |
| --- | --- | --- |
| **일반 파일** | 텍스트 또는 바이너리 데이터 | 문서(문자 해석), 바이너리(코드 해석) |
| **디렉토리 파일** | 파일/하위 디렉토리 정보 저장 | 파일 액세스를 위한 정보 보유 |
| **링크 파일** | 바로가기 또는 사본 기능 | **Hard Link**: 원본과 동일한 i-node 공유 (동기화됨)
**Symbolic (Soft) Link**: 원본의 위치만 포인팅 (바로가기) |
| **장치 파일** | 하드웨어 장치 관리 | `/dev` 아래 위치 (키보드, 마우스 등) |

> ⚠️ **링크 파일 상세 비교**
> 
> - **Hard Link:** 원본/사본 구분이 없음. 하나가 삭제되어도 데이터 유지. i-node 공유.
> - **Symbolic Link:** 원본 삭제 시 링크 파손(사용 불가).

## 2. 디렉토리와 파일 관리

### 🌲 계층형 트리 구조 (Tree Structure)

우분투(리눅스) 파일 시스템은 `/`(Root)에서 시작하여 가지처럼 뻗어 나가는 구조입니다.

- **작업 디렉토리:** 현재 위치 (`.` 으로 표시, `pwd`로 확인)
- **상위 디렉토리:** 부모 디렉토리 (`..` 으로 표시)
- **홈 디렉토리:** 사용자별 공간 (`~` 또는 `/home/계정명`)

### 📂 루트(/) 하위의 주요 디렉토리

- **`/bin`, `/usr/bin`**: 기본 실행 파일 (Binary)
- **`/boot`**: 부팅 관련 커널 파일
- **`/dev`**: 장치(Device) 파일
- **`/etc`**: 시스템 설정 파일 (Configuration)
- **`/home`**: 사용자 홈 디렉토리
- **`/lib`, `/usr/lib`**: 라이브러리 파일
- **`/mnt`, `/media`**: 파일 시스템/장치 마운트 포인트
- **`/root`**: 루트(Superuser) 계정의 홈
- **`/tmp`**: 임시 저장소 (재부팅 시 삭제됨)
- **`/var`**: 로그, 메일 등 자주 바뀌는 가변 데이터

### 📍 경로 (Path)

1. **절대 경로 (Absolute Path)**
    - 무조건 최상위 루트(`/`)부터 시작하는 경로
    - 예: `/home/adam/workspace`
2. **상대 경로 (Relative Path)**
    - 현재 위치를 기준으로 하는 경로
    - `.`(현재)과 `..`(상위) 이용
    - 예: `../images/logo.png`

> **Note:** **웹 프로그래밍** 등 실행 위치가 가변적인 환경에서는 **절대 경로를 사용하는 것이 안전**합니다.

## 3. 파일의 구성 요소

리눅스에서 파일 처리는 **이름**, **i-node**, **데이터 블록** 3가지 요소로 이루어집니다.

### 🏷️ 1. 파일 이름 (Filename)

- 사용자가 파일을 식별하기 위한 껍데기.
- **확장자:** 운영체제 차원에서는 의미 없음 (단순 식별용).
- **규칙:**
    - `/` 사용 불가 (경로 구분자).
    - 대소문자 엄격 구분 (`File` != `file`).
    - `.`으로 시작하면 **숨김 파일**.

### 🔢 2. i-node (Index Node)

- 파일의 실제 **메타데이터**를 담고 있는 핵심 구조.
- **저장 정보:** 소유권, 액세스 모드(권한), 타임스탬프, 데이터 블록 위치 등.
- 파일 생성 시 i-node 번호가 할당됩니다.

### 📦 3. 데이터 블록 (Data Block)

- 실제 파일의 내용(Contents)이 저장되는 디스크 공간.

> 💡 **작동 원리**
> 
> 
> 사용자 → 파일 이름 참조 → i-node 확인 → Data Block 접근
> 
> - 파일을 삭제한다는 것은 **i-node와의 연결(Link count)을 끊는 것**입니다.

## 4. 명령어 정리

### 🔍 파일 종류 확인: `file`

매직 파일(magic file)을 참조하여 파일의 종류를 식별합니다.

```bash
# 사용 형식
file [옵션] [파일명]

# 예시
file .profile       # ASCII text
file /bin/ls        # ELF 64-bit LSB executable (실행 파일)
file /usr/bin       # directory
```

### 📍 위치 확인 및 이동: `pwd`, `cd`

```bash
pwd                 # 현재 작업 중인 디렉토리의 절대 경로 출력

cd [디렉토리]       # 해당 디렉토리로 이동
cd                  # 홈 디렉토리(~)로 이동
cd ..               # 상위 디렉토리로 이동
```

### 📋 디렉토리 내용 확인: `ls`

```bash
ls [옵션] [경로]

# 주요 옵션
ls -a   # 숨김 파일 포함 전체 출력
ls -l   # 상세 정보 출력 (리스트 형식)
ls -F   # 파일 종류 표시 (*:실행, /:디렉토리, @:심볼릭링크)
ls -R   # 하위 디렉토리까지 모두 출력 (Recursive)
```

### 💡`ls -l` 출력 결과 해석

```bash
drwxr-x--- 4 adam adam 4096 Jan 7 08:16 myfile
```

1. **`d`**: 파일 종류 (`d`: 디렉토리, `-` : 파일, `l`: 링크)
2. **`rwxr-x---`**: 권한 (Permission)
    - 소유자(`rwx`) / 그룹(`r-x`) / 기타(`--`)
3. **`4`**: 하드 링크의 수 (Link count)
4. **`adam`**: 소유자 (Owner)
5. **`adam`**: 그룹 (Group)
6. **`4096`**: 파일 크기 (Byte)
7. **`Jan 7 08:16`**: 마지막 수정 시간
8. **`myfile`**: 파일 이름

## 5. 디렉토리 생성 및 삭제

### 🛠 디렉토리 생성: `mkdir`

```bash
mkdir [이름]

# 옵션 -p: 중간 경로가 없으면 자동 생성 (Parents)
mkdir -p temp/mid/han  # temp와 mid가 없어도 한 번에 생성
```

### 🗑 디렉토리 삭제: `rmdir`

**주의:** `rmdir`은 디렉토리가 **비어있을 때만** 삭제 가능합니다.

```bash
rmdir [이름]

# 옵션 -p: 하위 디렉토리 삭제 후 상위도 비어있으면 연쇄 삭제
rmdir -p temp/mid/han
```

## 5. 파일 관련 명령 (File Manipulation)

### 👁️ 파일 내용 확인 (Viewing)

| **명령어** | **설명** | **주요 옵션 / 특징** |
| --- | --- | --- |
| **cat** | 파일 내용을 화면에 연속 출력 | `-n`: 행 번호 표시
파일 병합이나 간단한 출력에 사용 |
| **more** | 화면 단위로 내용을 끊어서 출력 | `Space`: 다음 페이지, `b`: 이전 페이지, `q`: 중단
하단에 진행률(%) 표시 |
| **less** | more의 개선판 (양방향 스크롤) | 방향키, `j`/`k`로 스크롤 가능.
파일 전체를 로딩하지 않아 대용량 파일에 유리 |
| **head** | 파일의 앞부분 출력 (기본 10행) | `head -n 5`: 앞 5줄만 출력 |
| **tail** | 파일의 뒷부분 출력 (기본 10행) | **`tail -f [파일]`**: 실시간 로그 감시에 필수 (매우 중요 ⭐) |

### 🛠️ 파일 조작 (Copy, Move, Remove)

### 1. 복사 (`cp`)

파일이나 디렉토리를 복사합니다.

**형식 :** cp [옵션] [원본] [목표]

**주요 옵션**

- `r` : **Recursive**. 디렉토리를 내부 파일까지 포함하여 통째로 복사할 때 필수.
- `i` : **Interactive**. 덮어쓰기 상황이 발생할 경우, 사용자에게 확인(`y/n`)을 요청.

### 2. 이동 및 이름 변경 (`mv`)

파일을 다른 위치로 옮기거나, 이름을 바꿀 때 사용합니다. 별도의 옵션보다는 사용 방식이 중요합니다.

**형식 :** mv [원본] [목표]

**사용 예시**

- **이동:** `mv file.txt /tmp/` (파일을 /tmp 디렉토리로 이동)
- **이름 변경:** `mv old.txt new.txt` (같은 경로에서 이름만 변경)

### 3. 삭제 (`rm`)

파일이나 디렉토리를 삭제합니다. **복구가 어렵으므로 주의**해야 합니다.

**형식 :** rm [옵션] [파일]

**주요 옵션**

- `r` : **Recursive**. 디렉토리를 삭제할 때 사용 (내부 파일 포함 강제 삭제).
- `f` : **Force**. 삭제 여부를 묻지 않고 강제로 삭제 (경고 메시지 무시).
- `rf`: (조합) 묻지 않고 하위 디렉토리까지 전부 삭제. (가장 강력하고 위험한 명령)

> **⚠️ 주의사항**
> 
> - `rmdir` 명령어는 **빈 디렉토리**만 삭제할 수 있어 실무에서는 잘 쓰이지 않습니다.
> - 대부분 디렉토리 삭제 시 `rm -r` 또는 `rm -rf`를 사용합니다.

### 🔗 링크 생성 (`ln`)

리눅스의 바로가기 및 백업 메커니즘입니다.

> 💡 **하드 링크 vs 심볼릭 링크**
> 
> - **하드 링크 (Hard Link):** 동일한 **i-node**를 가리키는 이름만 하나 더 생성. 원본이 삭제되어도 데이터는 살아있음. (파티션 간 생성 불가)
> - **심볼릭 링크 (Symbolic/Soft Link):** 윈도우의 '바로가기'와 같음. 원본 경로를 가리킴. 원본 삭제 시 링크 깨짐 (`ln -s` 옵션 사용).

```bash
ln target linkname      # 하드 링크 생성 (i-node 동일)
ln -s target linkname   # 심볼릭 링크 생성 (i-node 다름)
```

### 🔎 검색 및 필터링 (`grep`, `find`)

### 1. grep (Global Regular Expression Print) ⭐

파일 내에서 특정 문자열(패턴)을 검색합니다.

- **기본:** `grep "문자열" [파일]`
- **옵션:**
    - `i`: 대소문자 무시
    - `r`: 하위 디렉토리까지 재귀 검색
    - `n`: 라인 번호 출력
    - `v`: 패턴이 **포함되지 않은** 행 출력
- **Context Mapping (문맥 확인):**
    - `A 3`: 매칭된 줄 **After** (뒤) 3줄
    - `B 3`: 매칭된 줄 **Before** (앞) 3줄
    - `C 3`: 매칭된 줄 **Context** (앞뒤) 3줄

```bash
# 실무 활용 예시: 포트 확인
netstat -an | grep "LISTEN"

# 실시간 로그에서 "Error" 강조 및 앞뒤 문맥 확인
tail -f access.log | grep -C 3 --color "Error"
```

### 2. find

파일 시스템에서 조건에 맞는 파일을 찾고 특정 동작을 수행합니다.

- **형식:** `find [경로] [조건] [동작]`
- **조건:** `name`(이름), `type`(f:파일, d:디렉토리), `newer`(시간), `size`, `user`
- **동작:** `print`(출력/기본값), `exec`(명령 실행)

```bash
# 현재 디렉토리(.)에서 확장자가 .txt인 파일 찾기
find . -name "*.txt"

# 확장자가 .swp인 파일을 찾아 삭제 (exec)
find ~ -name "*.swp" -exec rm {} \;
```

### 📊 텍스트 처리 도구

- **`wc` (Word Count):** 줄(`l`), 단어(`w`), 문자(`c`) 수 계산.
- **`sort`:** 정렬. `r`(역순), `n`(숫자 기준), `k`(필드 기준).
- **`awk`:** 텍스트를 컬럼 단위로 처리하는 강력한 도구.
    - 예: `awk '{print $1, $2}' file.txt` (1, 2번째 컬럼만 출력)
- **`sed`:** 스트림 편집기. 치환(`s`)에 주로 사용.
    - 예: `sed 's/old/new/' file.txt` (old를 new로 치환)

## 6. 파일 접근 권한 관리 (Permissions)

### 🔐 권한의 개요 (Permission)

ls -l 명령어로 확인 가능한 파일의 속성입니다.

예: -rwxr-xr--

1. **구성:** `유형(1)` + `소유자(3)` + `그룹(3)` + `기타(3)`
2. **권한 값:**
    - **r (Read, 4):** 읽기 (디렉토리는 `ls` 가능)
    - **w (Write, 2):** 쓰기/수정 (디렉토리는 파일 생성/삭제 가능)
    - **x (Execute, 1):** 실행 (디렉토리는 `cd` 진입 가능)

### ⚙️ 권한 변경 (`chmod`)

파일의 모드(Change Mode)를 변경합니다.

### 1. 숫자 모드 (8진수)

가장 많이 사용하는 방식입니다. `r(4) + w(2) + x(1)`의 합계로 설정.

- **7 (4+2+1):** 읽기/쓰기/실행 전체 허용
- **6 (4+2):** 읽기/쓰기 허용 (실행 불가)
- **5 (4+1):** 읽기/실행 허용 (수정 불가)

```bash
chmod 755 file.sh
# 소유자(7): rwx (모두 가능)
# 그룹(5): r-x (읽기/실행)
# 기타(5): r-x (읽기/실행)
```

### 2. 기호 모드

- 대상: `u`(User), `g`(Group), `o`(Other), `a`(All)
- 연산: `+`(추가), (제거), `=` (지정)

```bash
chmod g+w test.txt  # 그룹에 쓰기 권한 추가
chmod o-x test.txt  # 기타 사용자 실행 권한 제거
```

### 🎭 기본 권한과 umask

파일/디렉토리 생성 시 적용되는 기본 권한 설정값입니다.

- **리눅스 대원칙:** 새로 만든 일반 파일은 보안상 **절대 실행 권한(x)을 주지 않는다.** (파일 최대 666, 디렉토리 최대 777)
- **umask:** 기본 권한에서 **제외할** 비트를 지정.
    - 예: `umask 002` → 디렉토리는 775, 파일은 664가 됨.
- **스크립트 실행:** 파일을 만든 후 반드시 `chmod +x`를 해줘야 실행 가능.

### 🛡️ 특수 접근 권한 (Special Permissions)

기본 3자리 권한 앞에 붙는 4번째(가장 앞) 자리입니다.

| **이름** | **값** | **표시** | **설명** | **예시** |
| --- | --- | --- | --- | --- |
| **SetUID** | **4** | `s` (User) | 실행 시 **파일 소유자(Root 등)의 권한**을 잠시 빌려 씀. | `/usr/bin/passwd` (일반 유저가 암호 변경 시 root 권한 필요) |
| **SetGID** | **2** | `s` (Group) | 실행 시 파일 소유 그룹의 권한을 빌려 씀. | 협업 디렉토리 설정 등 |
| **Sticky Bit** | **1** | `t` (Other) | 누구나 쓸 수 있지만(**rwx**), **삭제는 소유자만** 가능. | `/tmp` 디렉토리 |

```bash
# SetUID 설정 예시 (4000번대)
chmod 4755 set.exe
# 결과: -rwsr-xr-x (x 자리가 s로 변경됨)
```
