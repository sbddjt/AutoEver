## 📖 Introduction
**현대오토에버 모빌리티 SW 스쿨 3기 클라우드 트랙**에서 진행한 Python 프로그래밍 학습 리포지토리입니다.
클라우드 네이티브 환경 및 데이터 처리를 위한 기초 언어로서 Python의 핵심 문법(Core Syntax), 객체 지향 프로그래밍(OOP), 그리고 고급 기능(Advanced Features)을 체계적으로 학습하고 실습한 코드를 정리했습니다.

단순한 문법 습득을 넘어 **Pythonic한 코드 작성법(The Zen of Python)**과 **효율적인 메모리 관리**, **모듈화**에 중점을 두었습니다.
