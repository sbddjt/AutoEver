# 📂 파일 처리 및 네트워크 개요

## 1. 파일 처리의 기본 원리 ⚙️

- **동작 방식**: 프로그램이 직접 파일을 건드리는 것이 아니라, **운영체제(OS)**에게 파일 처리를 요청합니다.
- **프로세스**: 프로그램 ➡️ 운영체제(요청) ➡️ 운영체제 작업 수행 ➡️ 프로그램(결과 반환).
- 실제 파일 핸들링의 주체는 **OS**입니다. 🛡️

## 2. 외부 작업과 예외 처리 ⚠️

- **외부 작업의 종류**: `File`, `Network`, `Database` 등
- **예외 처리의 필수성**:
    - 프로그램 외부 자원은 내가 제어할 수 없는 영역입니다.
    - 파일이 없거나, 네트워크가 끊기는 등 예기치 못한 상황이 발생할 확률이 높으므로 **반드시 예외 처리**가 수반되어야 합니다. 🛠️

## 3. 네트워크 및 프로세스 식별 🌐

서비스를 구별하고 찾아가기 위해 다음과 같은 식별자가 사용됩니다.

- **IP 주소**: 네트워크상에서 특정 컴퓨터(호스트)를 찾아가는 주소입니다. 📍
- **포트 번호 (Port)**:
    - 하나의 컴퓨터 내에서 실행 중인 특정 **서비스(애플리케이션)**를 구별합니다.
    - 개발자나 사용자가 직접 설정할 수 있어 관리가 편리합니다. ✨
- **PID (Process ID)**:
    - OS가 프로세스끼리 구분하기 위해 부여하는 고유 번호입니다.
    - **OS가 자동으로 결정**하기 때문에 사용자가 제어하기 어렵습니다. 🤖

- **결론**: 로컬 호스트 통신이나 서버 설정 시에는 **포트 번호**를 지정하여 사용하는 것이 효율적입니다.

## 4. 파일 처리 과정 (Life Cycle) 🔄

파일을 다룰 때는 반드시 아래의 **3단계** 과정을 거쳐야 합니다.

1. **파일 오픈 (open)** 🔓
    - 파일 포인터를 생성하여 파일에 접근할 권한을 얻습니다.
2. **파일 작업 (읽기, 쓰기)** ✍️
    - 생성된 파일 포인터를 이용해 데이터를 입력하거나 출력합니다.
3. **파일 클로즈 (close)** 🔒
    - 작업을 마치면 반드시 닫아주어야 합니다.
    - **이유**: 메모리 누수를 방지하고, OS가 잡고 있는 자원을 해제하기 위함입니다.

## 5. Open 함수 활용 🛠️

### **✍️ 파일 쓰기 (Write)**

파일에 데이터를 기록하고자 할 때는 보통 2개에서 3개의 매개변수를 사용하여 파일을 개방합니다.

- **매개변수 구성**: `(파일 경로, 'w', 인코딩 방식)`
    - **인코딩**: `ms949`, `cp949`, `euckr` 등을 지정하며, 생략 시 시스템 기본 인코딩이 적용됩니다.
- **기록 방법**:
    - `파일포인터.write(내용)`: 일반적인 문자열 기록.
    - `파일포인터.writelines(리스트)`: 줄바꿈(`\n`)이 포함된 리스트 등을 한꺼번에 기록할 때 사용합니다.
    - `''join(리스트)`: 문자열 사이에 특정 구분자를 넣어 기록할 때 유용합니다.

### **📖 파일 읽기 (Read)**

매개변수를 생략하거나 `'r'` 모드로 설정하면 읽기 모드로 파일이 개방됩니다.

- **전체 읽기**: `read()` 함수를 사용하여 파일 전체를 하나의 문자열로 가져옵니다.
- **줄 단위 읽기**: `readline()`(한 줄씩) 또는 `readlines()`(모든 줄을 리스트로)를 사용합니다.
- **부분 읽기**: `read(정수)`를 사용하면 입력한 정수 바이트(Byte)만큼만 읽어서 리턴합니다.

## 6. 파일의 경로 설정 (Path) 📍

프로그램이 읽거나 쓸 파일이 어디에 있는지 알려주는 방식입니다.

- **절대 경로 (Absolute Path)**: 루트(Root) 디렉토리부터 파일까지의 전체 경로를 모두 작성하는 방식입니다. (예: `C:\Users\AutoEver\...`)
- **상대 경로 (Relative Path)**: 현재 작업 중인 디렉토리를 기준으로 경로를 설정하는 방식입니다.
    - `./` : 현재 디렉토리 (생략 가능)
    - `../` : 상위 디렉토리

## 💻 실습 코드 (File I/O)

### 🔹 파일 기록 및 읽기 예제

```python
# 1. 파일 쓰기 예제
try:
    # 파일을 기록할 수 있도록 open
    file = open('./test.txt', 'w')

    # 파일에 한번에 기록
    file.write("Hello Python")
    file.write("\n\n")

    # 줄바꿈이 있는 문자열을 줄 단위로 기록
    msg = "Hello\nPython"
    file.writelines(msg)
    file.write(''.join(msg))

except Exception as e:
    print("파일 처리 중 예외 발생", e)
finally:
    file.close()

# 2. 파일 읽기 예제
try:
    # 파일을 읽어올 수 있도록 open
    file = open("./test.txt")

    '''# 한 번에 읽기
    msg = file.read()
    print(msg)'''

    # 줄 단위로 읽어서 처리
    for line in file:
        print(line)
        print("-----------")
    
except Exception as e:
    print("파일 처리 중 예외 발생", e)
finally:
    file.close()
```

### 🔹 문자열 조작 및 형변환

```python
# 문자열을 분할해서 문자열 list 만들기 
msg = "123 345 765 12"
result = msg.split(" ")
print(result)

# 문자열을 숫자로 변경하고자 할 때는 int(문자열), float(문자열)

print(int(result[0]) + int(result[1])) # 산술 연산 (468)
```

## 7. Serializable (직렬화) 🧊

> 정의: 인스턴스(객체)를 파일에 기록하거나 네트워크로 전송 가능한 형태로 변환하는 것
> 
- 응용 프로그램이 객체 상태 그대로 파일에 기록하고 나중에 다시 읽어올 때 사용합니다.

### **⚙️ 핵심 함수**

- **기록 시:** `pickle.dump(출력할 데이터, 파일객체)`
- **읽기 시:** `pickle.load(파일객체)` (1개씩 읽기) 또는 `loads` 활용

### 💡 직렬화가 필요한 이유 (Why?)

- **데이터 '상태' 보존** 💾
    - 일반 `write()`는 **문자열**만 저장하지만, 직렬화는 **데이터 타입, 변수 관계, 구조**를 통째로 저장함.
- **복구의 편리함** ⚡
    - 복잡한 파싱(Parsing) 과정 없이, 함수 하나로 원래 파이썬 객체로 **즉시 부활**.

### **🛠️ 실무 활용 팁 (Must-Know)**

| **구분** | **핵심 내용** | **비고** |
| --- | --- | --- |
| **바이너리 모드** | 반드시 `'wb'`, `'rb'` 모드로 열기 | 이진 데이터(Binary)이므로 필수 |
| **클래스 유지** | 읽어올 때 소스에 **클래스 정의**가 있어야 함 | 설계도가 없으면 조립 불가 |
| **보안 주의** | 신뢰할 수 없는 외부 `pickle` 파일은 로드 금지 | 악성 코드 실행 위험 존재 |

### 💻 직렬화 실습 코드

```python
import pickle

class VO:
    def __init__ (self, num = 0, name = "nonname"):
        self.num = num
        self.name = name

vo1 = VO(1, "adam")
vo2 = VO(2, "eve")

li = [vo1, vo2]

# 객체 기록 (Binary 쓰기 모드 'wb' 필수)
'''
f = open('./test.txt', 'wb')
pickle.dump(li, f)
f.close()
'''

# 객체 읽기 (Binary 읽기 모드 'rb' 필수)
f = open('./test.txt', 'rb')
result = pickle.load(f)

for r in result:
    print(f"번호: {r.num}, 이름: {r.name}")
f.close()
```
